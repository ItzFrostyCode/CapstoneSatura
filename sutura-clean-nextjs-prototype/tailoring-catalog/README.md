# Tailoring / Costume Shop Bulk Category List (Simplified)

This folder structure contains the top 5 essential categories for the Sutura tailoring ecosystem.

## Categories Included:
1.  **Philippine Traditional Wear**: Barong Tagalog, Filipiniana, Cultural/Ethnic.
2.  **Sports Uniforms**: Basketball, Volleyball, Soccer/Football, Other Sports.
3.  **Intramurals / School Events**: Team Shirts, Cheerdance, Festival/Events.
4.  **PNP / Police Related**: PNP Uniforms, Tactical Accessories.
5.  **School Uniforms**: Preschool, Elementary, High School, College.

## Usage
* **Folder structure**: Use this as a reference for organizing digital assets (photos, patterns).
* **Product categories**: Map these to your e-commerce or ERP category system.
* **Database seed**: Import `catalog.json` to populate your database tables.
